# Research Structure Atlas V1 — implementation plan

## Final product

A local, evidence-grounded research-navigation system. It represents public study–claim–test bundles as comparable cells, maps only conservative cross-domain structural relationships, emits plain-language verdicts, and routes any potential question through the existing closed-evidence and three-target gates.

## Six implementation steps

| Step | Deliverable | Completion evidence | Current state |
| --- | --- | --- | --- |
| 1. Research-cell language | Schema and contract for source, system, design, measurement, inference, validation, fragility, provenance, and decision blocks | Schema validation and unit tests | Complete for V1 seed |
| 2. Initial corpus | Exactly nine diverse cells, including adverse and blocked cases | Public source/data locations and explicit acquisition states | Complete as a seed; three records remain inventory-only |
| 3. Conservative graph | Typed structural roles and edges that retain mismatches | Deterministic graph with no topic-word edges | Complete for seed |
| 4. Owner-facing atlas | Readable comparison report with one verdict | Generated report and no hidden promotion | Complete for seed |
| 5. Strategic-lead screen | Explain which cells may enter candidate generation and why | Machine-readable acceptance/rejection ledger | Complete for seed |
| 6. Prospective proof loop | One atlas-derived, independently admissible target enters the existing gauntlet and is evaluated | Three-target packet, primary/reserve survivors, then normal execution gates | Not started; correctly blocked until a lead passes Step 5 |

## Action loop from this point

1. Choose one `gated` cell with a documented structural comparison.
2. Freshly acquire its official public files; record version and checksum.
3. Audit raw units, variables, baseline, independent partition, and claim boundary.
4. Run direct prior-art and simpler-explanation attacks.
5. If it fails, keep the rejection. If it passes, form a domain-specific lead.
6. Never form a trio until exactly three independently admissible leads exist.

## V1 boundary

The nine-cell seed validates the representation, comparison, and non-promotion behavior. It does **not** yet validate large-scale automated intake, strategic-question quality, or the original cross-domain discovery thesis. Those claims require Step 6.
