# Conservative execution cost policy

The Milestones 3–5 tranche began with the weekly meter at 68% used.

## Meter gates

- Check after each bounded batch.
- Normal target stop: 74–76% used.
- Absolute stop: 78% used.
- Do not repeat successful retrieval, extraction, or validation batches.
- Retry only failed records.

## Routing

- Deterministic code: retrieval, normalization, deduplication, validation, provenance checks, scoring arithmetic, sensitivity calculations, and tests.
- Economy extraction: bounded classification and schema population only after deterministic contracts exist.
- Balanced scientific review: source relevance, disputed classifications, translation claims, scoring rationales, and finalist selection.
- Strongest reasoning: excluded from Milestones 3–5 unless unresolved architecture, safety, or repeated verification failure requires it.

The active root model cannot be silently rewritten. Model recommendations apply at task or continuation boundaries. In this tranche, deterministic extraction replaced a separate economy-model pass wherever rules could do the work more cheaply, with balanced review retained at scientific decision points.
