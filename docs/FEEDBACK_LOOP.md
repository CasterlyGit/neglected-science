# Local feedback loop and evaluation standard

## Operating boundary

Neglected Science improves through public evidence, governed computations, the owner, and this local system. It does not contact specialists or simulate specialist review. When interpretation materially depends on unavailable domain expertise, the system must either narrow the claim to the self-contained evidence record or reject the target.

## One improvement cycle

1. Preserve an investigation result, including negative, null, and uncertain outcomes.
2. Evaluate selection quality, execution integrity, information value, and method learning against the standard below.
3. Emit one bounded improvement proposal with evidence, affected gate, expected benefit, risks, and a change level.
4. The owner approves or rejects the direction and level. No level-1-or-higher behavior change is applied without that approval.
5. Implement the approved improvement with a schema/test where feasible, then evaluate it in the next real investigation.

## Noncompensatory evaluation standard

| Dimension | Passing evidence | Failure consequence |
|---|---|---|
| Selection quality | Primary and reserve pass construction, novelty, readiness, and self-contained-interpretation checks | Do not count it as a valid method selection. |
| Execution integrity | Versioned preregistration, partitions, checksums, frozen final invocation, durable receipt | Do not use the result to promote the method. |
| Information value | Any outcome changes a bounded published-claim interpretation | Retain it as negative evidence. |
| Method learning | A miss or success changes a gate, schema, test, or limitation | Do not claim self-improvement. |
| Claim discipline | No claim exceeds the record | Correct the record first. |

The first two dimensions are gates, not scores.

## Owner-approved change levels

| Level | Change | Approval |
|---|---|---|
| 0 | Preserve evidence only | No |
| 1 | Safeguards: checks, schemas, tests, receipts | Direction and level |
| 2 | Target-selection, preregistration, or evaluation method | Direction and level |
| 3 | Scope, external interaction, publication, or authority | Explicit scope |

One investigation never authorizes Level 3. `verification/improvement-cycle-1.json` records the approved Level-1 safeguards from the E. coli run.
