# System-1 selector v2

## Trigger

Two fixed batches found the same bottleneck: source-feasible records could reproduce an existing analysis but did not contain a distinct, consequential robustness or reconciliation question.

## Change

Before a record receives full source-and-fragility audit, it must state:

1. a named, source-specific artifact, confounder, reconciliation decision, or validation gap that the primary analysis does not already resolve; and
2. a domain-specific positive, null, and contrary consequence. Each outcome must change interpretation of a bounded published claim.

The record is rejected before audit when either condition is absent. This change does not raise candidate-survival targets or lower any existing source, data, novelty, or execution gates.

## Test

Apply v2 to a contrasting, blinded held-out batch. Evaluate every record using the predeclared corpus-quality benchmark, retain all failures, and compare quality—not survival—with v1.
