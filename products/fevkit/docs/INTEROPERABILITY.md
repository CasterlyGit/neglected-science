# Interoperability boundary

FEVKit does not define a replacement research-object package. It exports an RO-Crate graph with a Process Run profile declaration and adds FEVKit-specific Function, Evidence, claim, and assurance terms.

The exporter is an implementation scaffold. Formal conformance language remains provisional until reviewed by Workflow Run or RO-Crate maintainers. If the mapping conflicts with upstream practice, FEVKit must change rather than fork the standard.
