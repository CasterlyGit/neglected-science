# Evaluation policy

Evaluation is captured as evidence, not inferred from a polished answer.

A V3 computation requires a declared baseline or control, explicit metrics, uncertainty characterization, robustness or failure analysis, replayable computation, and an approved human checkpoint. V4 additionally requires prospective independent evaluation and E6 observations.

Profiles may require more, but never less, than the cumulative stage definition. A profile name is not certification that the method is appropriate for the named biomedical task.
