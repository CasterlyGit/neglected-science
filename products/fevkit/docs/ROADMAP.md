# Evidence-gated roadmap

## Released in 0.1.0

Core run contract, deterministic audit, replay safeguards, SARIF, RO-Crate export, fixtures, tests, browser inspector, deployment, and review outreach package.

## Gate A — framework fidelity

A Function–Evidence–Validation framework author or equivalently qualified reviewer identifies no blocking semantic mismatch, or the mismatch is corrected.

## Gate B — standards boundary

A Workflow Run or RO-Crate maintainer reviews one generated crate. Conformance wording is changed or removed if challenged.

## Gate C — real adapter

One upstream scientific-agent team supplies a sanitized trace and reviews a narrow adapter. No second adapter begins before the first exposes actual information loss and maintenance cost.

## Gate D — external utility

A benchmark or research team shows that FEVKit catches an actionable trajectory failure not apparent from its existing final result artifact.

No marketplace, hosted data plane, clinical workflow, or generalized autonomous-science product begins before these gates.
