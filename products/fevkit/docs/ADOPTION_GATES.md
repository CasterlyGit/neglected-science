# Adoption gates

FEVKit is implementation-complete for an alpha but not externally validated.

The product crosses from internally coherent to externally supported only when:

- a framework reviewer accepts or repairs the semantic mapping
- a provenance maintainer accepts or repairs the Process Run export boundary
- a scientific-agent team provides a real sanitized trace
- one external user runs the gate in CI or a reproducible workflow
- the tool exposes a failure that an existing final-answer artifact hid

Until then, public language must use “alpha,” “review-ready,” and “independent implementation,” not “validated,” “standard,” “adopted,” or “trusted.”
