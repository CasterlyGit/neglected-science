# Data policy

FEVKit is local-first. The CLI reads local bundles and sends no telemetry. The browser inspector processes only the selected JSON file in browser memory and has no upload endpoint.

The manifest requires an explicit personal-data attestation and flags contradictions between sensitive inputs and the privacy declaration. These checks do not replace authorization, consent, access controls, encryption, retention, redaction, breach response, or institutional policy.

Public fixtures must remain synthetic and contain no patient, specimen, proprietary, or credential material.
