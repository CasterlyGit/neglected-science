# Anti-goals

FEVKit is not:

- a medical device or treatment recommender
- a biological truth detector
- a generic scientific chatbot
- a replacement for peer review, clinical governance, IRB review, quality systems, or regulation
- a new provenance packaging standard
- a hosted patient-data platform
- a universal trust score
- proof that an undisclosed step did not occur

Any proposal that requires one of these identities should be implemented elsewhere or rejected.
