A biomedical agent can sound right, call tools correctly, and still run the wrong science. FEVKit turns its actual run into an inspectable Function profile, Evidence profile, and defensible Validation stage.

Files stay in your browser. No analytics, account, database, or upload endpoint.

Auditable does not mean clinically valid.
FEVKit checks inspectability, lineage, replay prerequisites, claim support, and declared validation evidence. It cannot decide whether a treatment is safe, a biological interpretation is true, or a workflow satisfies a regulation.
